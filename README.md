# Electrcity Bill Calculator

## Description 

This program calculates the electricity bill. 

## Version 1 - Original code without input validation

- Input: Accepts a user's name and the two readings
- Process: Calculates and displays the electricity consumption and the total bill.
- Output: Name, electricity consumption, and the total bill.
- Does not include input validation for the program. 

## Version 2 - Code with input validation

- Input: Accepts a user's name and the two readings.
- Process: Calculates and displays the electricity consumption and total bill.
- Output: Name, electricity consumption, and the total bill.
- Input Validation: Validates the user's name if it is there or isn't. Validates the electricity consumption through the previous electricity consumption if it is at least 0 or less, and the current electricity concumption if it is at least the previous electricity consumption or less.
